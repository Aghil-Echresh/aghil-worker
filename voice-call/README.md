# تماس صوتی با ایمیل | Aghil Email Voice Call

نسخهٔ آزمایشی تماس صوتی دوطرفه با WebRTC و سرور سیگنالینگ Socket.IO. مناسب برای بررسی اولیه روی موبایل و دسکتاپ.

## امکانات
- ورود آزمایشی با واردکردن ایمیل
- فهرست ایمیل‌های آنلاین
- درخواست تماس، قبول یا رد تماس
- انتقال صدا با WebRTC
- endpoint بررسی سلامت در `/health`

## استقرار روی Render
1. در Render یک سرویس **Web Service** بساز و این مخزن را وصل کن.
2. مقدار **Root Directory** را `voice-call` قرار بده.
3. Runtime را Node انتخاب کن؛ Build Command: `npm install` و Start Command: `npm start`.
4. بعد از Deploy، آدرس HTTPS سرویس را در دو دستگاه باز کن.
5. هر دو کاربر ایمیل خود را ثبت کنند. سپس یکی ایمیل دیگری را وارد کرده و تماس بگیرد.
6. اجازهٔ میکروفون را بده؛ مرورگر برای دسترسی به میکروفون به HTTPS نیاز دارد.

## محدودیت‌ها و امنیت
- در این نسخه ایمیل **شناسه است، نه احراز هویت**؛ کد تأیید ایمیل یا رمز عبور پیاده‌سازی نشده و هر فرد می‌تواند ایمیلی را وارد کند. برای انتشار عمومی، ابتدا احراز هویت واقعی اضافه شود.
- سرور در حافظه فهرست کاربران آنلاین را نگه می‌دارد؛ با restart همه از سیستم خارج می‌شوند.
- برای عبور پایدار از NAT و شبکه‌های محدود، TURN server با اعتبارنامهٔ امن لازم است. نسخه فعلی فقط STUN عمومی دارد و ممکن است در برخی شبکه‌ها تماس برقرار نشود.
- برای سرویس عمومی، محدودیت نرخ، مجوز تماس، کنترل مبدأها و مانیتورینگ اضافه شود.
- برای تست اولیه از اطلاعات حساس استفاده نکن.

## اجرای محلی
Node.js 20 یا بالاتر لازم است:
```bash
npm install
npm start
```
سپس `http://localhost:3000` را باز کن. برای تست میکروفون روی دستگاه‌های دیگر از HTTPS استفاده کن.
